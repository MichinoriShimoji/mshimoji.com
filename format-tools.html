Interlinear Glossed Textへの自動変換ツールAutomatic conversion tools for Interlinear Glossed Text

← グロスづけ支援に戻る← Back to Glossing Support

エクセルで、あるいはELANファイルで管理している例文データを、一般的な例文提示フォーマット（Interlinear Glossed Text）に自動で整えてくれるツールを紹介します。開発は下地理則。

We introduce tools that automatically format example data managed in Excel or ELAN files into the standard Interlinear Glossed Text (IGT) format. Developed by Michinori Shimoji.

🛠️ IGT Builder

エクセルファイルに (1) 方言テクスト、(2) 形態素ごとのグロス、(3) 全文訳を書いて管理しておけば、あとはエクセルをアップロードするだけで綺麗なIGT形式にしてWordで吐き出します。画像保存もできるのでPPT資料などにも便利です。

If you manage your data in Excel with (1) dialect text, (2) morpheme-by-morpheme glosses, and (3) free translations, simply upload the file to get cleanly formatted IGT output in Word. You can also save as images for use in PowerPoint presentations.

🔧 eaftox

ELANのeafファイルにある例文データを文単位に自動で切り出し、音声ファイルも同時に切り出し、文ごとにLaTeXのgb4eスタイルのリストとtxtファイルのIGT形式リストを吐き出します。普段LaTeXを使う人はeaftoxが便利です。

Automatically extracts example data from ELAN .eaf files sentence by sentence, along with corresponding audio clips, and outputs LaTeX gb4e-style lists and IGT-formatted .txt files for each sentence. Ideal for LaTeX users.
