# テクスト→地図ジェネレーター

地名を含む日本語テクストを入力すると、内容を解析して注釈付きの日本白地図を
**3案**（広域 / 標準 / 詳細）自動生成するウェブツールです。
すべての処理はブラウザ内で完結します（サーバー通信なし）。

## 使い方

- **ウェブ**: https://michinorishimoji.github.io/japan-text-map/ を開き、テクストを入力して「地図を生成」
- **ローカル**: このフォルダをダウンロードして `index.html` をダブルクリック（`file://` でも動作します）

### 機能

- 都道府県・市区町村・政令市・郡・町字（大字、全国約11.8万件）・駅名（全国約8,900駅）・
  島・地方名（九州、琉球列島など）を自動検出
- ヶ/ケなどの表記ゆれを吸収（「恋ヶ窪」でも「恋ケ窪」でもヒット）
- 市町村はドット＋ラベル、島は引き出し線付きラベル、地方は破線囲みで表示
- 「県境」「市町村境界」などの語に反応して境界線の表示を切り替え
- 同名の自治体（例: 府中市）は文脈の都道府県から自動解決。解決できない場合は
  既定で除外し、チップのクリックで表示に含められます
- 各案は SVG / PNG でダウンロード可能
- 注釈モードを選択可能: 地名ラベル+ドット (既定) / ドットのみ / 注釈なし
- ズームの深さに応じてラベル・ドットの大きさを自動調整
- 生成するとテクストが URL（`#q=...`）に保存され、リンクを共有するだけで
  同じ地図を再現できます

## ファイル構成

```
index.html        UI本体
app.js            TopoJSONデコーダ・地名辞書・テクスト解析・SVG描画
data/japan_pref.js   都道府県ポリゴン (TopoJSON, script埋め込み形式)
data/japan_muni.js   市区町村ポリゴン (同上)
data/places.js       島・地方名の補助辞書 (地名を足したいときはここに追記)
data/chome.js        町字辞書: 市区町村コード → [大字名, 経度, 緯度] の一覧
data/stations.js     駅辞書: [駅名, 市区町村コード, 経度, 緯度] の一覧
```

同名地名の扱い: 複数候補がある地名（「本町」は全国に約280か所）は、テクスト中の
市区町村・都道府県から絞り込み、特定できない場合は既定で除外されます
（検出チップをクリックすれば全候補を表示に含められます）。

ズームの決め方: 「福岡市博多区の御供所町」のように、言及された町字・駅を含む
市区町村は住所の文脈（所在の説明）とみなし、表示範囲の計算や強調表示から
外します。焦点が町字・駅だけの場合は数km四方まで自動でズームします。

地図データを `<script>` 埋め込みにしているのは、`file://` で開いたときに
`fetch()` が使えないためです。ウェブ配信でもこのままで問題ありません。

## GitHub Pages での公開

このフォルダの中身をリポジトリに置き、Settings → Pages で公開するだけです
（ビルド不要）。ファイルを更新したときは `index.html` 内の `?v=` の番号を
上げると、閲覧者のキャッシュが確実に更新されます。

## 生成した地図を論文・書籍等に使う場合

地図画像にはクレジットが焼き込まれています。トリミング等でクレジットを外す場合は、
キャプション等に次のように記載してください:

> 国土数値情報（行政区域データN03・鉄道データN02）および
> Geolonia住所データを加工して作成

## データ出典・ライセンス

- 行政区域ポリゴン: 国土交通省「国土数値情報（行政区域データ N03）」を
  [smartnews-smri/japan-topography](https://github.com/smartnews-smri/japan-topography)
  が簡略化したデータ（2021年版）を同梱しています。
  利用の際は国土数値情報の出典明記が必要です（地図内クレジットに記載済み）。
- 駅辞書: 国土交通省「国土数値情報（鉄道データ N02、2024年版）」の駅位置から生成。
- 町字辞書: [Geolonia 住所データ](https://github.com/geolonia/japanese-addresses)
  （国土交通省「位置参照情報」ベース、CC BY 4.0）から大字レベルに集約して生成。
- 行政区域データを新しい年度に更新する場合は、上記リポジトリの
  `data/municipality/topojson/s0010/` から取得し、
  `window.MUNI_TOPO=` / `window.PREF_TOPO=` を先頭に付けて
  `data/*.js` を置き換えてください。駅・町字辞書の再生成スクリプトは
  開発リポジトリの `process_gazetteer.R` を参照。
