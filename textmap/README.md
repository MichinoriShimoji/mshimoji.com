# テクスト→地図ジェネレーター

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.21766019.svg)](https://doi.org/10.5281/zenodo.21766019)

地名を含む日本語テクストを入力すると、内容を解析して注釈付きの日本白地図を
**3案**（広域 / 標準 / 詳細）自動生成するウェブツールです。
すべての処理はブラウザ内で完結します（サーバー通信なし）。

## 使い方

- **ウェブ**: https://michinorishimoji.github.io/japan-text-map/ を開き、テクストを入力して「地図を生成」
- **ローカル**: このフォルダをダウンロードして `index.html` をダブルクリック（`file://` でも動作します）
- **解説記事**: [テクストを貼るだけで言語・方言の分布地図ができるツールを作った（note）](https://note.com/lingfieldwork/n/n55ff8b169b1e)

### 機能

- 都道府県・市区町村・政令市・郡・町字（大字・小字、全国約18.5万件）・駅名（全国約8,900駅）・
  島・地方名（九州、琉球列島など）を自動検出
- 鉄道路線を可視化: 路線名（「中央線」）はその路線を、会社の通称（「西武線」）は
  言及された駅を通るその会社の路線だけを描画
- 学校（大学〜小中学校 約3.5万校）・病院（約8,200院）のランドマークに対応
  （「東京学芸大学」「◯◯市立◯◯小学校」など。設置者接頭辞や高等学校⇔高校のゆれも吸収）
- 旧市町村（1920年以降に廃止された全国約1.4万自治体: 旧具志川市、平良市など）と
  沖縄の間切（明治期の行政区分: 読谷山間切など約50件）にも対応
- 旧字（あざ）などデータにない地名は `data/places.js` の CUSTOM_PLACES に追記して拡張可能
- ヶ/ケなどの表記ゆれを吸収（「恋ヶ窪」でも「恋ケ窪」でもヒット）
- 市町村はドット＋ラベル、島は引き出し線付きラベル、地方は破線囲みで表示
- 「県境」「市町村境界」などの語に反応して境界線の表示を切り替え
- 同名の自治体（例: 府中市）は文脈の都道府県から自動解決。解決できない場合は
  既定で除外し、チップのクリックで表示に含められます
- 各案は SVG / PNG でダウンロード可能
- 生成後は地図上で直接編集可能: ラベル・ドットのドラッグ移動、ダブルクリックで
  文字編集、右クリックで削除、「注釈を全部消す」で白地図化 (編集結果は保存に反映)
- ズームの深さに応じてラベル・ドットの大きさを自動調整
- 生成するとテクストが URL（`#q=...`）に保存され、リンクを共有するだけで
  同じ地図を再現できます

## ファイル構成

```
index.html        UI本体
app.js            TopoJSONデコーダ・地名辞書・テクスト解析・SVG描画
data/japan_pref.js   都道府県ポリゴン (TopoJSON, script埋め込み形式)
data/japan_muni.js   市区町村ポリゴン (同上)
data/places.js       島・地方名の補助辞書 (地名を足したいときはここに追記)
data/chome.js        町字辞書 (大字+小字): 市区町村コード → [名前, 経度, 緯度] の一覧
data/stations.js     駅辞書: [駅名, 市区町村コード, 経度, 緯度, [路線添字]] の一覧
data/rail.js         鉄道路線ポリライン (路線名・会社ごと)
data/landmarks.js    ランドマーク辞書 (学校・病院): [名称, 市区町村コード, 経度, 緯度, 種別]
data/hist.js         旧市町村辞書
```

同名地名の扱い: 複数候補がある地名（「本町」は全国に約280か所）は、テクスト中の
市区町村・都道府県から絞り込み、特定できない場合は既定で除外されます
（検出チップをクリックすれば全候補を表示に含められます）。

ズームの決め方: 「福岡市博多区の御供所町」のように、言及された町字・駅を含む
市区町村は住所の文脈（所在の説明）とみなし、表示範囲の計算や強調表示から
外します。焦点が町字・駅だけの場合は数km四方まで自動でズームします。

地図データを `<script>` 埋め込みにしているのは、`file://` で開いたときに
`fetch()` が使えないためです。ウェブ配信でもこのままで問題ありません。

## GitHub Pages での公開

このフォルダの中身をリポジトリに置き、Settings → Pages で公開するだけです
（ビルド不要）。ファイルを更新したときは `index.html` 内の `?v=` の番号を
上げると、閲覧者のキャッシュが確実に更新されます。

## 生成した地図を論文・書籍等に使う場合

地図画像にはクレジットが焼き込まれています。トリミング等でクレジットを外す場合は、
キャプション等に次のように記載してください:

> 国土数値情報（行政区域N03・鉄道N02・学校P29・医療機関P04）、Geolonia住所データ、
> 歴史的行政区域データセットβ版（CODH）を加工して作成

## データ出典・ライセンス

- 行政区域ポリゴン: 国土交通省「国土数値情報（行政区域データ N03、2024年版）」を
  mapshaper で簡略化（許容誤差約50m・市区町村単位に集約）して同梱しています
  （再生成手順は開発リポジトリの scripts/build_topo.sh）。
  利用の際は国土数値情報の出典明記が必要です（地図内クレジットに記載済み）。
- 鉄道路線・駅辞書: 国土交通省「国土数値情報（鉄道データ N02、2024年版）」から生成
  （路線は許容誤差約50mで簡略化）。
- ランドマーク辞書: 国土交通省「国土数値情報（学校データ P29、2023年版／
  医療機関データ P04、2020年版）」から生成（病院は病院分類のみ収録）。
- 町字辞書: [Geolonia 住所データ](https://github.com/geolonia/japanese-addresses)
  （国土交通省「位置参照情報」ベース、CC BY 4.0）から大字・小字レベルに集約して生成。
- 旧市町村辞書: [歴史的行政区域データセットβ版](https://geoshape.ex.nii.ac.jp/city/)
  （CODH／国立情報学研究所、CC BY 4.0）のGeoNLP辞書から廃止自治体を抽出して生成。
- 間切辞書: 明治期の沖縄県の区・間切一覧をもとに手作業で作成（座標は中心集落の概算）。
- 行政区域データを新しい年度に更新する場合は、国土数値情報から全47県の
  N03 シェープファイルを取得し、開発リポジトリの `scripts/build_topo.sh`
  (mapshaper による簡略化・TopoJSON化・JS埋め込みまで自動) を実行してください。
  駅・町字辞書の再生成スクリプトは開発リポジトリの `process_gazetteer.R` を参照。
